# Aviatest 4.21

Актуальные исходники двух вариантов на 12 ноября 2026 года:

- `MIP` — МИП.
- `MGPU` — МГПУ.

Каждая папка содержит приложение, ресурсы, настройки методик, тесты,
инструкцию 4.21 и сценарий сборки `build-release.ps1`.
Основная точка входа — `aviatest_v4_21.py`.
Зависимости перечислены в `requirements-build.txt` соответствующего варианта.

Демонстрационные аккаунты являются частью программы. Рабочие данные
участников, журналы и локальные учётные записи в репозиторий не включены.
Старые версии исходников доступны в истории Git.
